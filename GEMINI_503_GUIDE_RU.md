# Freedom CQA — ошибка Gemini 503 (перегрузка)

`STEP 1: HTTP 200` — ключ и доступ к метаданным работают. `STEP 2: HTTP 400` — специально неверный запрос отвергнут, как ожидалось. `STEP 3: HTTP 503 UNAVAILABLE` — Google принял запрос генерации, но модель перегружена. Это не ошибка чек-листа и не означает исчерпание квоты пользователя.

## Установка патча

1. Остановите `run_windows.bat` через `Ctrl+C`.
2. Создайте резервную копию `C:\Freedom_CQA_Gemini\llm.py`. Сохраните без изменений `.env` и `cqa.sqlite3`.
3. Скопируйте новый `llm.py` и `list_gemini_models.py` в `C:\Freedom_CQA_Gemini`.
4. Запустите `py list_gemini_models.py` из папки проекта (если библиотек в обычном Python нет, используйте `.\.venv\Scripts\python.exe list_gemini_models.py`). Выберите из списка **реально доступный** альтернативный flash-модельный ID.
5. В `.env` добавьте или измените:

```ini
CQA_LLM_PROVIDER=gemini_native
CQA_LLM_MODEL=gemini-3.8-flash
CQA_LLM_HTTP_RETRIES=2
CQA_LLM_FALLBACK_MODELS=ВПИШИТЕ_РЕАЛЬНУЮ_РЕЗЕРВНУЮ_МОДЕЛЬ
CQA_BATCH_WORKERS=1
CQA_BATCH_DELAY_SEC=8
```

Не копируйте `ВПИШИТЕ_...` буквально; замените на имя модели из вывода скрипта. Можно перечислить несколько моделей через запятую. Если запасной модели нет, оставьте `CQA_LLM_FALLBACK_MODELS=` пустым.

6. Перезапустите `run_windows.bat`. После отдельной проверки подключения откройте интерфейс и оцените **один** диалог. Потом запускайте пакетную обработку.

## Поведение при ошибках

- `503 / 502 / 504 / 500`, а также тайм-аут: после повторных попыток переключает вызов на заданную запасную модель.
- `429`: прекращает обработку и показывает причину; смена модели может не решить ограничение квоты проекта.
- `400 / 401 / 403 / 404`: не скрывает ошибку и не переключает модель, поскольку это чаще конфигурация, права или неверный запрос.
- Если все модели недоступны, сохранение результатов оценки не происходит; ошибка видна пользователю.
- Использование запасной модели помечается `model_info.fallback_used=true`; в `model_info.model` сохраняется фактическое имя модели.

**Уточнение:** список моделей, возвращённый API, не гарантирует возможность генерации именно на бесплатном тарифе. Проверяйте любую выбранную модель отдельным коротким запросом. Отправляйте реальные звонки только если есть разрешение на обработку соответствующих данных внешней моделью.
