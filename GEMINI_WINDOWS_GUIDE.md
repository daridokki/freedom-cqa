# Freedom CQA + Gemini — полная пошаговая инструкция для Windows

## 0. Что это за программа
Браузер показывает интерфейс HTML/CSS/JavaScript. Локальный FastAPI-сервер получает запросы и хранит диалоги/оценки в SQLite. `llm.py` отправляет текст операторского разговора и версию чек-листа в Gemini через официальную OpenAI-compatible точку `/chat/completions`. Ответ Gemini должен содержать восемь ответов с причинами и номерами реплик. `scoring.py` валидирует шкалы и по формуле из чек-листа рассчитывает баллы. Изменения критериев и апелляции хранятся в базе.

## 1. Подготовка
1. Установите Python 3.11+ с https://www.python.org/downloads/ (на Windows желательно опция PATH).
2. Распакуйте ZIP в простую папку, например `C:\Freedom_CQA_Gemini`. Не запускайте Python из ZIP-архива.
3. Скопируйте `.env.example` в `.env` (Вид → Показать → Расширения имён файлов). Важна точка перед env.
4. Создайте API key в https://aistudio.google.com/api-keys. Вставьте секрет только в `.env`, заменив пустое значение `CQA_LLM_API_KEY=` на `CQA_LLM_API_KEY=ваш_ключ`. Ключ нельзя публиковать.
5. Оставьте `CQA_LLM_MODEL=gemini-2.5-flash` если модель доступна вашему проекту. Если не доступна — возьмите точный идентификатор модели из AI Studio, где есть доступ Free Tier.

## 2. Запуск и проверка
6. Двойным кликом запустите `run_windows.bat`. Дождитесь строки `Uvicorn running on http://127.0.0.1:8000`.
7. **Не закрывайте** окно с сервером. Откройте `http://127.0.0.1:8000` в браузере.
8. В отдельном окне запустите `check_gemini_windows.bat`. Он посылает **один небольшой реальный запрос** к Gemini без ваших клиентских диалогов. При успехе увидите `GEMINI API: OK`. `model_configured: true` в `/api/health` означает лишь наличие ключа, **не** успешное подключение.
9. Если ошибку `404` даёт модель — выберите доступную в AI Studio модель и перезапустите `run_windows.bat`. `401` — проверьте ключ; `429` — ограничения запросов / доступная квота.

## 3. Загрузка датасета
10. Скачайте отдельно подготовленный файл `Freedom_CQA_DEV_65.json`. В архив проекта его специально **нет**, чтобы случайно не выгрузить данные диалогов в публичный GitHub.
11. В интерфейсе откройте «Диалоги» → «Загрузить JSON» → выберите `Freedom_CQA_DEV_65.json`. Появятся 65 записей (35 RU, 15 KZ, 15 EN; 60 чатов и 5 звонков).
12. Откройте один диалог `p1-ru-022` и нажмите «Оценить». Получите реальную оценку модели, если ключ, модель и квота работают.
13. Проверьте, что в критерии «Грубые ошибки» стоит «ДА» (предложен перевод денег на личную карту); ссылки на реплики должны соответствовать тексту. Это **ожидаемый** результат, а не заранее гарантированный ответ Gemini.
14. Протестируйте также `p1-ru-009` (идентификация), `p1-ru-025` (N/A и ранний уход), один KZ и один EN диалог.
15. Только после успешных единичных прогонов нажмите «Оценить новые». Программа обрабатывает диалоги по одному с паузой 8 секунд (настраивается `CQA_BATCH_DELAY_SEC`) и сохраняет прогресс. Уточняйте лимиты конкретного проекта в https://aistudio.google.com/usage.

## 4. Результаты, апелляции, чек-листы
16. Во вкладке «Результаты» откройте оценку: каждый критерий показывает ответ, баллы, объяснение, ссылки «Реплика #». Итог рассчитывается Python, не Gemini.
17. Чтобы оспорить критерий, заполните апелляцию и сохраните. Во вкладке «Апелляции» проверьте, подтвердите или измените оценку; сохранится оригинал и обновится финальная сумма.
18. Во вкладке «Чек-лист» измените правило, вес или шкалу; сохранение создаёт новую версию. Затем снова запустите оценку для демонстрации обработки нового критерия без изменений кода.
19. При необходимости экспортируйте результаты в CSV и отдельный отчёт в JSON.

## 5. Частые ошибки
- `Python was not found`: установить Python с опцией PATH или проверить `py --version`.
- `No module named ...`: повторно запустить `run_windows.bat` при доступном интернете; он ставит зависимости.
- `model_configured:false`: `.env` лежит не рядом с `app.py`, либо не заполнен ключ.
- `401/403`: недействительный или ограниченный ключ / проект без доступа.
- `404`: идентификатор модели недоступен или указан с ошибкой.
- `429`: квота / RPM / RPD проекта, уменьшите нагрузку или дождитесь сброса лимита.
- `AI response did not meet ...`: модель вернула невалидную структуру после двух попыток. Проверьте лог сервера, повторите один диалог, попробуйте другую доступную модель.
- `Address already in use`: закройте ранее запущенную копию сервера.
- `run_windows.bat` сразу закрывается: запустите в PowerShell из папки `cmd /k run_windows.bat` и посмотрите ошибку.

## 6. Безопасность
На бесплатном тарифе Google может использовать отправленный контент для улучшения продуктов. Не отправляйте реальные звонки с персональными данными без разрешения организаторов и разрешённой политики обработки. Данных из DEV в ZIP нет. Не публикуйте `.env`, `*.sqlite3`, приватные транскрипты и подписанные URL организаторов. Программа локальная и без авторизации, как допускает ТЗ; не раскрывайте её в открытый интернет.

## 7. Полезные команды PowerShell (альтернатива двойному клику)
```powershell
cd C:\Freedom_CQA_Gemini
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
# Отредактируйте .env и вставьте ключ, затем:
.\.venv\Scripts\python.exe check_gemini.py
.\.venv\Scripts\python.exe -m uvicorn app:app --host 127.0.0.1 --port 8000
```

### Автоматические тесты
Чтобы проверить проект без обращения к Gemini, запустите `run_tests_windows.bat`. Ожидаемый результат: 17 тестов пройдено.

## 8. Ограничения тестирования
Установленная локально версия проходит unit/integration тесты с имитацией ответов LLM. Без вашего API-ключа невозможно подтвердить реальную работу Gemini на ваших данных. `check_gemini.py` проводит отдельную настоящую проверку ключа на вашем компьютере.
